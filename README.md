# 小功能（xiaotoolkit）

EchoMusic 插件：单击播放 + 歌词沉浸 + 顶部插件按钮 + 桌面特效 + 多账号切换。

> 本仓库为 [小功能](https://github.com/Max8808)（作者：张三 + Max8808）的二改版本，主要增加**多账号切换**相关能力。

## 功能

- **单击播放**：点击歌曲条目立即播放，无需再点播放按钮
- **歌词沉浸**：歌词界面完全沉浸，隐藏干扰元素
- **顶部插件按钮**：在顶部栏提供插件快捷入口
- **桌面特效**：10 种粒子特效（雪花、火焰、极光、爱心、彩带、星星、枫叶、樱花、花瓣、线条），使用 OffscreenCanvas + Web Worker 渲染，粒子动画跑在独立线程，切歌不卡
- **多账号切换**：侧栏一键切换账号，切换后自动刷新用户信息
- **独立开关**：每个功能都可以在插件设置面板中单独开启或关闭

## 环境要求

- EchoMusic `>= 2.2.6-beta.20`
- 需要宿主提供 `kugouApi` 能力

## 安装

1. 将本仓库整个文件夹放入 EchoMusic 的插件目录：

   ```
   xiaotoolkit/
   ├── manifest.json    # 插件清单，声明所需能力
   ├── index.js         # 主逻辑：各功能实现与设置面板
   └── icon.svg         # 插件图标
   ```

2. 回插件管理点**刷新**（或重启宿主），启用「小功能」
3. 点插件卡片上的**设置**，按需开关各个功能

## 文件

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 插件清单，声明所需能力与版本要求 |
| `index.js` | 主逻辑：单击播放、歌词沉浸、桌面特效、多账号切换、设置面板 |
| `icon.svg` | 插件图标 |
